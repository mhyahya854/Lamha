Canonical source: `semantic-plan-source/phases/implementation-phases.json` and the reviewed work-package registry.

- Objective: Preserve provenance and establish a reproducible non-destructive baseline before application changes.
- Entry gate: Active plan, source hashes, and write boundaries are verified.
- Exit gate: Repository/toolchain/component facts and baseline attempts are recorded without changing application source.

- `WP-I0-005` — Toolchain inventory: Implement and verify the bounded toolchain inventory surface.

- `WP-I0-008` — Missing fixture classification: Implement and verify the bounded missing fixture classification surface.
- `WP-I0-009` — Frontend coupling inventory: Implement and verify the bounded frontend coupling inventory surface.
