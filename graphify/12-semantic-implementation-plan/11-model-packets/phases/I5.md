# I5 — Offline Library Experience

Canonical source: `semantic-plan-source/phases/implementation-phases.json` and the reviewed work-package registry.

- Objective: Deliver the usable offline gallery, viewers, albums, memories, map browsing, Review Centre, and saved views.
- Entry gate: I4 discovery and preview/index contracts exist.
- Exit gate: Core browsing and review workflows operate from local data with keyboard/error coverage.

## Reviewed work packages

- `WP-I5-001` — Gallery grid and virtualization: Render the gallery grid from local records with adjustable density, fast thumbnail cache loading within budget, and keyboard-operable retained components.
- `WP-I5-002` — Timeline navigation: Navigate the timeline by date from local records, render event/folder browsing, mark missing-media and offline-drive states, and preserve prior position on load failure.
- `WP-I5-003` — Image viewer: Implement and verify the bounded image viewer surface.
- `WP-I5-004` — Video viewer: Implement and verify the bounded video viewer surface.
- `WP-I5-005` — Selection and keyboard navigation: Implement and verify the bounded selection and keyboard navigation surface.
- `WP-I5-006` — Albums and favorites: Implement and verify the bounded albums and favorites surface.
- `WP-I5-007` — Memories experience: Implement and verify the bounded memories experience surface.
- `WP-I5-008` — Location and map browsing: Render maps, venues, offline coordinates, asset timelines by location, location filters, and review links from canonical location records; keep optional map tiles disabled by default and never mutate records.
- `WP-I5-010` — Review-state mutations: Commit and persist review-state transitions (approve, reject, suppress, defer, mark intentional, record decision, apply to selection) with provenance and revision while leaving navigation and filtering in separate read packages.
- `WP-I5-011` — Saved views and filters: Implement and verify the bounded saved views and filters surface.
- `WP-I5-012` — Offline library parity proof: Implement and verify the bounded offline library parity proof surface.
- `WP-I5-013` — Read and navigation surfaces: Load and display review items, assets, events, people, and provenance without mutating authoritative state; opening an item never changes its state.
- `WP-I5-014` — Review filters and queue operations: Filter review queues by confidence and source and advance through items one by one or by skipping without changing item state.
- `WP-I5-015` — Filesystem reveal and open operations: Reveal physical paths in the OS file manager or open folders in the UI without moving files, authorizing roots, or mutating state.
- `WP-I5-016` — Person, event, and asset detail loading: Load and display asset, person, event, sidecar, and duplicate detail views from local records without mutating the loaded records.
- `WP-I5-017` — Asset viewer mutation actions: Apply viewer-originated mutations (bundle treat classification, tag editing, event assignment) through the reviewed authority and plan boundaries without modifying original media.

This packet is an index. Execute one work-package packet at a time and respect the dependency graph.
