# No-early-delete rules

- Phase 0/1: no Codebase mutation or deletion.
- Later phases: no deletion without exact current path/symbol/caller/consumer/test/config/runtime mapping.
- A retained behavior needs a verified local replacement before the old subsystem disappears.
- Baseline/rollback evidence, affected focused/regression/build/desktop-launch proof, and source-verified Graphify/Ponytail agreement are mandatory.
- Generated clients, manifests, docs, environment variables, installers, and launch paths are part of removal scope.
- Phase 16 removes only residues or items whose complete prerequisites first pass there, then performs repository-wide release reverification.
